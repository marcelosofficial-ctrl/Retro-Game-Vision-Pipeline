# Provenance and failure modes

The system is designed to answer not only "what number did it produce?" but also **"what evidence was allowed to influence that number?"**

## Provenance rules

- Original images are preserved privately.
- Derived crops/grids are analysis layers, not replacements for the original asset.
- A physical observation retains a link to the source asset.
- OCR / visual candidate output can propose an identity, but accepted identity is a separate state transition.
- Market rows retain their evidence type and compatibility context.
- Hypothetical price scenarios remain derived and never overwrite the photographed shelf price.

## Conservative failure modes

The system prefers `RESEARCH` over a confident but unsupported number when market evidence is weak, edition compatibility is unresolved, required contents are not visible, evidence freshness cannot be established, or a dealer headline does not match the exact physical copy.

A false `BUY` is more expensive than an explicit request for one more photo.
