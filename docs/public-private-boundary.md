# Public / private boundary

The public repository is intentionally not the production application.

## Public

- domain-model examples;
- simplified compatibility logic;
- synthetic demo data;
- regression tests;
- architecture documentation;
- publication-safety checks.

## Private

- production SQLite database and backups;
- real store photographs and evidence crops;
- real market datasets and URLs;
- source-specific scraping/research adapters;
- production valuation weights and threshold policy;
- operational shopping UI and CLI;
- checkpoint archives and sourcing notes.

The engineering can be evaluated without publishing the operational advantage or redistributing third-party market data.
